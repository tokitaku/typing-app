# Tailwind CSS v4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `frontend` に Tailwind CSS v4 を最小差分で導入し、既存 UI を大きく壊さずに utility class を解決できる状態にする。

**Architecture:** 変更は `frontend` のビルド基盤に限定する。`package.json` と `postcss.config.mjs` で Tailwind の解決経路を追加し、`globals.css` を入口にして既存の手書き CSS と共存させる。表示上の変更は Tailwind が実際に使えることを示す最小 1 箇所に限定し、`shadcn/ui` 導入や既存 class の置換は後続 issue に残す。

**Tech Stack:** Next.js 14, React 18, TypeScript, Vitest, Tailwind CSS v4, PostCSS
